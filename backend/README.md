An AI-powered Study Assistant built using:

- FastAPI
- React
- PostgreSQL
- OpenAI API

## Features

- AI Chat
- Notes Generator
- Quiz Generator
- PDF Upload
- Authentication

## Tech Stack

Backend:
- FastAPI
- SQLAlchemy
- PostgreSQL

Frontend:
- React
- Vite
- Tailwind CSS
